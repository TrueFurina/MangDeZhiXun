## 测评报告数据来源说明

### 测评报告基于什么分析？
**数据来源**：
1. **测评数据**（来自测评中心）
   - 学生答题记录
   - 各维度得分（专业技能、通用能力、行为特质、经验背景）
   - 答题时长和正确率

2. **岗位要求数据**（来自岗位库）
   - 岗位维度权重
   - 行业标准
   - 能力要求阈值

3. **AI分析**（文心大模型）
   - 综合评价生成
   - 优势分析
   - 待提升项识别
   - 个性化成长建议

**分析流程**：
```
测评数据 + 岗位要求 → 多维度加权匹配算法 → 计算各维度得分 → 文心大模型分析 → 生成详细报告
```

**理论依据**：
- McClelland胜任力理论
- Spencer冰山模型
- Boyatzis整合模型

**算法创新**：
- 非线性匹配算法（考虑能力阈值效应）
- 动态权重调整（不同岗位权重不同）
- AI驱动的个性化分析
