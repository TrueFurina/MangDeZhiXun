## 理论依据说明

### 测评依据
本平台的测评体系基于以下理论：
1. **McClelland胜任力理论**：通过测评识别学生的深层次特征，预测岗位表现
2. **Spencer冰山模型**：测评表层特征（知识、技能）和深层特征（特质、动机）
3. **Boyatzis整合模型**：综合考虑个人能力、工作要求、组织环境

### 岗位匹配依据
匹配度计算公式：
```
匹配度 = Σ(学生维度得分 × 岗位维度权重 × 维度重要性) / 100
```

不同岗位的维度权重不同：
- **AI算法工程师**：专业技能50%、通用能力25%、行为特质15%、经验背景10%
- **产品经理**：专业技能30%、通用能力40%、行为特质20%、经验背景10%

推荐排序算法：
```
推荐分数 = 匹配度 × 0.6 + 岗位热度 × 0.2 + 薪资吸引力 × 0.1 + 地域匹配度 × 0.1
```

### 题目设计依据
1. **STAR原则**：情景题遵循Situation-Task-Action-Result结构
2. **难度分层**：基础30%、进阶50%、高级20%
3. **题型分布**：客观题60%、主观题30%、实操题10%
