# 「芒得职训」平台深度优化与改进路线图

> 生成时间：2026-03-12
> 版本：v185（含多企业对比 PDF 导出、能力匹配课程推荐、移动端导航修复）

## 一、产品功能深度优化

### 1.1 学员端：构建「能力成长闭环」
- **成长路径可视化**：引入「能力树」可视化，每个节点对应课程/测评，完成即点亮；展示从入学到目标岗位的完整成长曲线
- **学习计划智能生成**：基于能力匹配缺口 + 目标岗位，AI 自动生成 N 周学习计划（每周任务、预计耗时、里程碑），支持一键加入日历
- **学习打卡与激励**：每日学习打卡、连续学习天数、成就徽章（首份简历、首次面试、完成首个课程等），提升留存
- **模拟面试复盘库**：建立历史面试报告库，支持横向对比多次面试的进步曲线，AI 生成「面试能力趋势分析」
- **简历版本管理**：支持多版本简历管理（针对不同企业/岗位），一键对比优化前后差异，ATS 关键词命中率可视化
- **求职进度看板**：看板式管理投递企业、面试轮次、offer 状态，与「企业洞察」「多企业对比」数据联动

### 1.2 企业端：从「评估工具」升级为「招聘决策中枢」
- 候选人人才池：沉淀历次评估候选人，支持标签、备注、收藏，形成企业私有人才库
- 批量评估与对比：支持批量导入候选人、横向对比多候选人雷达图，一键生成「候选人排名报告」
- 岗位胜任力模型库：按岗位族（研发、产品、运营、销售）沉淀标准模型，新岗位一键套用
- 招聘漏斗分析：结合评估结果与招聘进度，分析各环节转化率，识别人才流失节点
- 企业招聘趋势看板：基于多企业对比数据，展示本企业 vs 竞品的人才吸引力趋势

### 1.3 院校端：从「数据看板」升级为「教学决策支持」
- 班级能力画像：聚合全班测评数据，生成班级整体雷达图，识别班级薄弱维度
- 课程效果归因：关联课程学习数据与测评结果变化，量化每门课程对能力提升的贡献度
- 就业质量分析：追踪毕业生去向、薪资、企业匹配度，反哺专业培养方案优化
- 预警机制：对能力停滞、学习活跃度下降的学生自动预警，推送干预建议
- 校企协同：院校端直接查看合作企业的胜任力模型与招聘需求，实现「按需培养」

### 1.4 新增高价值模块
- AI 职业规划师：多轮对话式职业咨询，结合用户画像生成个性化职业发展路径
- 行业人才地图：基于招聘数据生成行业人才分布热力图（地域、薪资、技能）
- 薪资谈判助手：基于多企业对比数据，AI 生成个性化薪资谈判话术与区间建议
- 面试官模拟：按目标企业风格（大厂八股、外企行为面试）定制面试官人设

## 二、用户体验与交互优化

### 2.1 导航与信息架构
- 全局搜索升级：扩展为「功能+内容+AI」三合一搜索（搜索页面、课程、历史报告、AI 问答）
- 面包屑导航：深层页面增加面包屑，避免用户迷失
- 快捷操作面板：`Cmd/Ctrl+K` 唤起命令面板，快速跳转任意功能

### 2.2 移动端体验
- 学员端核心功能（测评、课程、面试）做移动端优先适配
- 关键操作（提交测评、导出报告）增加移动端手势优化
- 考虑 PWA 支持，允许「添加到主屏幕」离线访问已下载课程

### 2.3 交互细节
- 加载状态统一：所有数据请求使用统一的骨架屏（Skeleton）
- 空状态引导：无数据页面提供明确的引导操作
- 操作反馈：关键操作（提交、导出、删除）统一使用 toast + 视觉确认
- 暗色模式完善：为图表（recharts）适配暗色主题色

### 2.4 无障碍（A11y）
- 所有交互元素补充 `aria-label`，键盘可达性测试
- 图表增加文字替代说明
- 色盲友好：图表使用形状+颜色双重编码

## 三、技术架构与性能优化

### 3.1 前端性能
- 代码分割优化：按路由组做预加载（`<Link>` hover 时预取）
- 图表性能：recharts 大数据量时考虑切换为更轻量的渲染方案或虚拟化
- 图片优化：课程封面、报告配图统一走 CDN + WebP，配合懒加载
- Bundle 分析：定期跑 `vite-bundle-visualizer`

### 3.2 后端与数据层
- Edge Function 缓存：招聘数据、行业数据等低频变动结果在 Edge 层做短期缓存
- 数据库索引审计：为高频查询字段（user_email、created_at、status）补充复合索引
- RLS 策略审计：当前部分表 RLS 较宽松（permissive），生产前需收紧为基于 `auth.uid()` 的严格策略
- 离线任务队列：深度研究等长任务改用 Supabase Queue + 后台 worker，避免 Edge Function 超时

### 3.3 可观测性
- 前端错误监控：接入 Sentry 或自建错误上报，捕获未处理异常
- 用户行为埋点：关键路径埋点（测评完成率、报告导出率、课程完播率）
- SLO 看板：基于已有的 error_log + performance_monitor 表，构建 SLO 看板
- 告警机制：错误率突增、Edge Function P95 超阈值时自动告警

### 3.4 架构演进
- 状态管理升级：引入 Zustand 或 TanStack Query 管理服务端状态
- API 层标准化：统一 `api.ts` 封装所有后端调用，集中处理错误、重试、缓存
- 类型安全：从数据库 schema 自动生成 TypeScript 类型

## 四、AI 能力深化

### 4.1 AI 体验升级
- 流式输出统一：所有 AI 生成内容统一流式输出
- 多模态支持：简历优化支持上传 PDF/图片简历（OCR 提取）；面试支持语音输入
- AI 可控性：为 AI 生成内容增加「重新生成」「局部编辑」「采纳/拒绝」的细粒度控制
- Prompt 工程化：将散落在 Edge Function 中的 prompt 集中管理，支持版本化、A/B 测试

### 4.2 智能化增强
- RAG 知识库：构建企业招聘趋势、行业报告的知识库
- 个性化模型：基于用户历史测评、学习数据微调推荐策略，实现「千人千面」
- Agent 编排：将「企业洞察→JD拆解→能力匹配→课程推荐→学习计划」串联为自动化 Agent 工作流
- AI 质量评估：对 AI 生成的报告自动评分，低分自动重试

## 五、数据价值挖掘

### 5.1 数据资产化
- 行业基准库：聚合所有用户查询的招聘数据，构建脱敏的行业薪资/技能基准库
- 能力趋势分析：跨用户聚合能力雷达数据，生成「大学生能力画像年度报告」
- 课程效果数据：量化每门课程对学员能力提升的贡献

### 5.2 数据可视化
- 个人数据看板：学员端「我的数据」页，展示学习时长、能力变化、求职进度全景
- 企业数据看板：企业端「人才洞察」页，展示候选人画像分布、招聘效率
- 院校数据看板：院校端「就业质量」页，展示就业率、平均薪资、对口率

## 六、商业化与运营

### 6.1 商业模式
- 会员体系深化：明确免费/付费功能边界，设计阶梯定价（基础版/专业版/企业版）
- 企业 SaaS 订阅：企业端按「候选人评估次数/月」或「席位」计费
- 院校解决方案：院校端按「学生数/年」打包销售
- 数据增值服务：行业人才报告、企业招聘趋势报告作为付费数据产品

### 6.2 增长运营
- 分享裂变：测评报告、能力雷达图支持生成精美分享海报
- 内容营销：基于深度研究功能批量生成行业分析内容
- SEO 优化：为公开页面做 SEO，承接搜索流量
- 用户分层运营：按活跃度分层，差异化推送内容与权益

## 七、安全与合规

### 7.1 数据安全
- 简历/个人信息加密：敏感字段（身份证、手机号）数据库层加密存储
- 数据导出审计：记录所有数据导出操作
- API 限流：Edge Function 增加按用户/IP 的速率限制
- RLS 收紧：生产前将所有 permissive 策略改为基于角色的严格策略

### 7.2 合规
- 个人信息保护法合规：隐私政策、用户协议、数据删除权（账号注销）
- AI 内容标识：AI 生成内容明确标注「由 AI 生成」
- 未成年人保护：若有未成年用户，增加监护人同意流程
