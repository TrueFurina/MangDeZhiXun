# 需求文档

## 1. 应用概述

### 1.1 应用名称
芒得职训·AI岗位胜任力智能服务平台

### 1.2 应用描述
本平台面向C端学生/职场新人、企业HR、高校就业办老师、系统运营管理员四类用户，提供AI驱动的岗位胜任力测评、人岗匹配、成长路径规划、AI个性化岗位实习培养、校企合作对接、AI智能就业咨询等核心功能。

**核心战略定位**：不做招聘投递平台（不与BOSS直聘竞争），专注「求职陪跑与靶向特训平台」，核心差异化在于：
1. 基于真实企业招聘数据+具体JD的精准拆解（对抗通用大模型泛泛练习）
2. 不做招聘投递，专注投递前的靶向武装

平台集成秒哒「企业招聘数据查询」插件（company-hiring-data），通过输入企业名称或统一社会信用代码，自动获取企业近三个月真实招聘数据（招聘岗位总数、平均薪资、招聘城市、招聘渠道及岗位分布等），赋能学生求职、企业招聘分析、高校校企合作企业核验、平台人岗匹配模型优化等场景，实现全流程真实数据驱动。

平台所有评估与咨询环节均由后台AI智能评估引擎驱动，实现「可量化、可追溯、可优化」的评估闭环。后端基于秒哒低代码平台后端服务构建（https://app-aateh5gojg1t.appmiaoda.com/），采用开发环境与线上环境双隔离架构，通过独立数据库实例实现业务数据安全存储,集成Auth认证授权体系，实现四端权限隔离与数据安全存储。

**本次更新核心模块**：
1. 性能与流畅度优化模块：系统性排查并优化首屏加载速度、路由懒加载、资源体积、运行时性能等，确保页面快速可访问
2. AuthGuard角色匹配校验模块：在现有登录态守卫基础上增加角色匹配校验，防止越权访问
3. 监控数据自动清理模块：为error_log和performance_monitor两张监控表增加自动清理超过30天记录的策略
4. 管理后台监控看板模块：在管理后台新增监控看板页面，展示Edge Function调用耗时趋势与错误统计
5. 用户体验深度优化模块：系统性提升整体用户体验，包括加载状态、空状态、错误提示、交互反馈、信息层级、移动端适配等
6. 网页内容总结功能模块（新增）：用户输入单条或多条网页链接，系统自动提取网页正文，生成精简摘要与核心要点，支持批量整理与信息提炼
7. 招聘数据查询功能增强模块（新增）：支持导出企业招聘数据、多企业对比分析、能力需求匹配分析

## 2. 用户与使用场景

### 2.1 目标用户
- C端用户：在校学生、职场新人，核心需求为确定目标企业-获取JD-拆解差距-靶向特训-简历优化-投递前武装
- 企业端用户：HR，核心需求为建胜任力模型-筛简历-做测评-招到人
- 高校端用户：就业办老师，核心需求为看就业数据-管学生-对接企业-优化培养方案-批量诊断学生简历-批量组织面试考核-质检课程内容与技能包
- 运营管理员：平台运营人员，核心需求为权限可控、数据可管、内容质量可控、合规风险可排查、系统性能监控

### 2.2 核心使用场景
- 学生输入目标企业名称（如「宁德时代」），系统调用company-hiring-data插件获取该企业宏观招聘数据（薪资分布、学历要求、经验要求分布），学生直观看到自身与企业要求的差距，点击「导出数据」按钮导出企业招聘数据PDF或Excel文件
- 学生同时输入多家目标企业名称（如「宁德时代」「比亚迪」「特斯拉」），系统调用company-hiring-data插件批量获取企业招聘数据，生成多企业对比分析报告（对比职位数、平均薪资、学历分布、经验要求等），学生查看对比结果后点击「导出对比报告」按钮导出PDF或Excel文件
- 学生查询企业招聘数据后，系统基于招聘数据中的学历要求、经验要求、岗位能力偏好，对标学生当前素养画像（测评结果），生成能力需求匹配分析报告，标注学生当前能力与企业要求的差距，给出针对性的能力提升建议，学生点击「查看提升建议」按钮查看详细建议并关联推荐站内课程
- 学生粘贴一条在BOSS直聘上看到的真实JD（如「宁德时代Java开发工程师」），系统解析JD拆解核心技能项、软素质要求、隐性门槛，与学生真实用户画像进行数据级比对，生成靶向雷达图差距分析
- 学生基于特定JD和画像差距，一键发起靶向AI深度压力面试，AI面试官根据JD要求与学生短板进行对抗性施压追问（如「该学生想去宁德时代面试Java开发，这份JD要求高并发经验，而学生画像显示他项目经验薄弱，请在面试中死死咬住高并发和项目落地细节进行对抗性施压追问」），生成深度面试报告
- 学生在AI沉浸式实训中心选择「全真单面模拟」，系统基于岗位类型生成结构化面试题，学生语音/文字作答，AI从表达逻辑、应变能力、岗位匹配度等维度实时评分，输出逐题点评+整体改进建议
- 学生在AI沉浸式实训中心选择「群面场景实训」，系统生成无领导小组讨论题目与角色设定，模拟多轮讨论场景，训练团队协作、沟通说服、总结汇报能力
- 学生在AI沉浸式实训中心选择「竞赛答辩模拟」，系统针对三创赛、挑战杯等创新创业赛事生成评委提问库，模拟答辩场景
- 学生上传简历PDF或粘贴个人经历文本，输入目标岗位JD（或一键拉取系统内的靶向JD记录），系统调用tailored-resume-generator-cn插件分析岗位匹配度，输出匹配打分，逐条标注「符合项/待优化项」，运用STAR法则和关键词匹配重写经历，生成针对性的优化简历、求职信、自我介绍，针对诊断出的简历短板（如缺项目经验、缺团队协作经历）自动关联推荐站内实训课程或虚拟练兵场任务
- 学生完成岗位胜任力测评，后台AI智能评估引擎自动评分，生成能力报告与成长建议
- 学生通过AI个性化岗位实习培养模块，获取专属能力全息图、精准实习路径规划、虚拟练兵场实操训练及动态调优反馈
- 学生通过AI智能就业咨询服务，获取简历优化建议、岗位精准匹配推荐、面试模拟训练、就业政策解答等全流程求职支持
- 学生做职业规划时，输入目标行业/岗位关键词，系统调用deepresearch技能生成目标行业/岗位深度研究报告，包含行业发展趋势、核心岗位能力要求、薪资水平、职业发展路径等
- 学生参加创新创业比赛时，输入项目主题或上传项目资料，系统调用deepresearch技能生成行业研究报告、竞品分析报告，辅助项目答辩与商业计划书撰写
- 学生看到长篇职场干货、行业文章、政策文件时，粘贴网页链接一键生成摘要，快速获取核心要点；批量整理求职面经、行业资料，节省阅读时间
- HR输入一句话岗位名称，AI自动生成胜任力模型、能力权重与面试问题，批量筛选候选人
- 高校老师在AI沉浸式实训中心自定义班级考核的面试方案，批量生成统一的面试题与评分标准，系统自动汇总班级面试成绩，生成各素养维度的班级整体薄弱点
- 高校老师查看就业数据看板与就业能力分析报告，管理学生能力画像，对接校企合作，批量导入学生简历生成班级整体常见问题汇总用于就业指导课
- 高校老师在教师辅用课程质检页面上传待评估的技能包、课程内容或测评题库，系统从结构完整性、表述清晰度、触发合理性、合规风险、可维护性5个维度自动检查，输出质量评分、风险等级与优先修复排序
- 高校老师做教学研究优化时，输入研究主题或上传调研资料，系统调用deepresearch技能生成行业人才需求调研报告，辅助培养方案优化与课程设计
- 高校老师生成年度就业质量分析报告时，输入分析主题或上传就业数据，系统调用deepresearch技能生成结构化分析报告，包含就业率、就业质量、行业分布、薪资水平等维度分析
- 高校老师批量整理就业政策、行业文章时，粘贴多条网页链接，系统批量生成摘要，提炼核心要点做成教学课件；汇总企业案例、职场文章整理成实训素材库
- 管理员在系统管理后台内容质量管理页面进行实训技能质检、测评体系迭代、内容合规审核，批量检查实训案例、课程内容的合规性，排查敏感内容
- 管理员在行业标准中心管理页面输入细分行业关键词，系统调用deepresearch技能生成《人才能力需求白皮书》，作为平台能力建模支撑，定期更新行业人才需求变化
- 管理员在行业标准中心管理页面查询多家企业招聘数据，生成多企业对比分析报告，导出PDF或Excel文件，用于行业人才需求分析
- 管理员为项目自身生成市场调研报告时，输入调研主题或上传资料，系统调用deepresearch技能生成结构化市场调研报告，用于比赛结题申报
- 管理员内容运营批量采集行业文章、企业案例时，粘贴多条网页链接，系统批量生成摘要，总结提炼后转化为实训场景素材；配合深度研究功能，批量处理参考网页，加速报告生成效率
- 管理员管理全平台用户、权限、内容与订单
- 管理员在监控看板页面查看Edge Function调用耗时趋势与错误统计，支持按时间范围筛选，快速定位性能瓶颈与异常问题
- 学员在实训过程中遇到陌生概念时，通过百度AI搜索功能一键搜索；做规划时查询行业动态；撰写求职信时搜索企业最新信息
- 院校老师备课时通过百度AI搜索功能搜最新政策、需求、案例；做分析时查最新就业数据、报告
- 管理员通过百度AI搜索功能搜最新真实职场场景；调研竞品动态
- 学员误访问企业端页面时，系统自动校验角色权限，跳转至学员端首页
- 企业HR误访问高校端页面时，系统自动校验角色权限，跳转至企业端首页
- 高校老师误访问管理后台页面时，系统自动校验角色权限，跳转至高校端首页

### 3.2 企业洞察子页（C端）（升级）（P0）

**页面定位**
展示目标企业宏观招聘数据，学生直观看到自身与企业要求的差距

**核心功能**
- 企业招聘数据展示：展示招聘规模、薪资分布、学历要求分布、经验要求分布、岗位分布数据
- 差距提示：基于学生画像与企业要求生成差距提示
- 导出数据：点击「导出数据」按钮，支持导出企业招聘数据PDF或Excel文件
- 多企业对比入口：点击「添加对比企业」按钮，支持添加多家企业进行对比分析
- 能力需求匹配分析入口：点击「查看能力匹配」按钮，跳转至能力需求匹配分析子页
- 百度AI搜索入口：页面顶部展示搜索框，学生输入问题后系统发起全网搜索，结合大模型整理成结构化答案，展示总结结果与来源链接
- 加载状态：数据加载时展示骨架屏或加载动画
- 空状态：企业招聘数据为空时展示空状态提示

**秒哒后端支撑**
- 企业招聘数据通过company-hiring-data插件获取
- 差距提示由AI智能评估引擎生成
- 导出功能调用秒哒后端服务生成PDF或Excel文件
- 百度AI搜索结果通过百度AI搜索API获取

### 3.3 多企业对比分析子页（C端）（新增）（P0）

**页面定位**
学生同时查询多家企业，对比不同企业的招聘数据差异

**核心功能**
- 企业选择：学生输入多家企业名称（支持2-5家企业），点击「开始对比」按钮
- 对比维度展示：
  + 招聘岗位总数对比（柱状图）
  + 平均薪资对比（柱状图）
  + 学历要求分布对比（堆叠柱状图）
  + 经验要求分布对比（堆叠柱状图）
  + 岗位类型分布对比（饼图）
  + 招聘城市分布对比（地图或列表）
- 对比结论：系统基于对比数据生成对比结论（如「宁德时代招聘规模最大，比亚迪平均薪资最高，特斯拉学历要求最严格」）
- 导出对比报告：点击「导出对比报告」按钮，支持导出PDF或Excel文件
- 百度AI搜索入口：页面顶部展示搜索框，学生输入问题后系统发起全网搜索，结合大模型整理成结构化答案，展示总结结果与来源链接
- 加载状态：数据加载时展示骨架屏或加载动画
- 错误提示：企业数据获取失败时展示友好错误提示

**秒哒后端支撑**
- 企业招聘数据通过company-hiring-data插件批量获取
- 对比结论由AI智能评估引擎生成
- 导出功能调用秒哒后端服务生成PDF或Excel文件
- 百度AI搜索结果通过百度AI搜索API获取

### 3.4 能力需求匹配分析子页（C端）（新增）（P0）

**页面定位**
基于企业招聘数据中的学历要求、经验要求、岗位能力偏好，对标学生当前素养画像，生成能力需求匹配分析报告

**核心功能**
- 企业要求展示：展示企业招聘数据中的学历要求、经验要求、岗位能力偏好
- 学生画像展示：展示学生当前素养画像（测评结果）
- 匹配度分析：
  + 学历匹配度：对比学生学历与企业学历要求
  + 经验匹配度：对比学生经验与企业经验要求
  + 能力匹配度：对比学生能力画像与企业岗位能力偏好，生成雷达图
- 差距标注：标注学生当前能力与企业要求的差距（如「学生当前项目经验不足，企业要求3年以上项目经验」）
- 能力提升建议：系统基于差距分析生成针对性的能力提升建议（如「建议参加Java高并发实战课程」「建议完成虚拟练兵场项目实训」）
- 课程推荐：自动关联推荐站内课程或虚拟练兵场任务
- 导出分析报告：点击「导出分析报告」按钮，支持导出PDF文件
- 百度AI搜索入口：页面顶部展示搜索框，学生输入问题后系统发起全网搜索，结合大模型整理成结构化答案，展示总结结果与来源链接
- 加载状态：数据加载时展示骨架屏或加载动画

**秒哒后端支撑**
- 企业招聘数据从秒哒数据库企业招聘数据表读取
- 学生画像从秒哒数据库用户画像表读取
- 匹配度分析由AI智能评估引擎生成
- 能力提升建议由AI智能评估引擎生成
- 课程推荐从秒哒数据库课程资源表读取
- 导出功能调用秒哒后端服务生成PDF文件
- 百度AI搜索结果通过百度AI搜索API获取

### 3.5 网页内容总结页（C端）（新增）（P0）

**页面定位**
学生输入单条或多条网页链接，系统自动提取网页正文，生成精简摘要与核心要点

## 4. 业务规则与逻辑

### 4.1 企业招聘数据获取规则
- 调用company-hiring-data插件，输入企业名称或统一社会信用代码，获取企业近三个月真实招聘数据
- 数据包含：招聘岗位总数、平均薪资、招聘城市、招聘渠道、岗位分布、学历要求分布、经验要求分布
- 数据获取失败时，提示「企业数据获取失败，请检查企业名称或稍后重试」

### 4.2 企业招聘数据导出规则（新增）
- 学生或管理员查询企业招聘数据后，点击「导出数据」按钮
- 系统调用秒哒后端服务生成PDF或Excel文件
- PDF文件包含：企业名称、查询时间、招聘岗位总数、平均薪资、学历要求分布、经验要求分布、岗位分布、招聘城市分布
- Excel文件包含：企业名称、查询时间、招聘岗位总数、平均薪资、学历要求分布、经验要求分布、岗位分布、招聘城市分布，支持数据筛选与排序

### 4.3 多企业对比分析规则（新增）
- 学生或管理员输入多家企业名称（支持2-5家企业），点击「开始对比」按钮
- 系统调用company-hiring-data插件批量获取企业招聘数据
- 系统生成多企业对比分析报告，对比维度包含：
  + 招聘岗位总数对比（柱状图）
  + 平均薪资对比（柱状图）
  + 学历要求分布对比（堆叠柱状图）
  + 经验要求分布对比（堆叠柱状图）
  + 岗位类型分布对比（饼图）
  + 招聘城市分布对比（地图或列表）
- 系统基于对比数据生成对比结论（如「宁德时代招聘规模最大，比亚迪平均薪资最高，特斯拉学历要求最严格」）
- 对比结论由AI智能评估引擎生成

### 4.4 能力需求匹配分析规则（新增）
- 学生查询企业招聘数据后，点击「查看能力匹配」按钮
- 系统从秒哒数据库企业招聘数据表读取企业招聘数据中的学历要求、经验要求、岗位能力偏好
- 系统从秒哒数据库用户画像表读取学生当前素养画像（测评结果）
- 系统生成能力需求匹配分析报告：
  + 学历匹配度：对比学生学历与企业学历要求
  + 经验匹配度：对比学生经验与企业经验要求
  + 能力匹配度：对比学生能力画像与企业岗位能力偏好，生成雷达图
- 系统标注学生当前能力与企业要求的差距（如「学生当前项目经验不足，企业要求3年以上项目经验」）
- 系统基于差距分析生成针对性的能力提升建议（如「建议参加Java高并发实战课程」「建议完成虚拟练兵场项目实训」）
- 系统自动关联推荐站内课程或虚拟练兵场任务
- 能力提升建议由AI智能评估引擎生成

### 4.5 JD拆解规则
- 学生粘贴真实JD文本或输入意向岗位关键词后，系统调用AI智能评估引擎解析JD
- 拆解维度：
  + 核心技能项：提取JD中明确要求的技术栈、工具、框架
  + 软素质要求：提取JD中隐含的软素质要求（如团队协作、沟通能力、抗压能力）
  + 隐性门槛：提取JD中未明确但实际存在的门槛（如985/211优先、大厂背景优先）
- 拆解结果存储于秒哒数据库JD拆解记录表

### 4.6 靶向雷达图差距分析规则
- 系统将JD拆解结果与学生真实用户画像进行数据级比对
- 比对维度：
  + 核心技能匹配度：对比JD核心技能项与学生画像中的技能标签、项目经验
  + 软素质匹配度：对比JD软素质要求与学生测评结果中的职业素养得分
  + 项目经验匹配度：对比JD项目经验要求与学生简历中的项目经验
  + 学历背景匹配度：对比JD学历要求与学生基本信息中的学历
  + 综合竞争力：综合以上四个维度计算综合竞争力得分
- 每个维度生成学生当前得分与JD要求得分的对比
- 标注短板项（得分低于JD要求10分以上的维度）与优势项（得分高于JD要求10分以上的维度）
- 生成差距详细说明与改进建议

### 4.7 AI沉浸式实训规则（升级）

#### 4.7.1 全真单面模拟规则
- 学生选择岗位类型、面试形式、难度等级后，系统调用conducting-interviews-cn技能生成结构化面试题
- 题目生成逻辑：
  + 从秒哒数据库行业标准题库表读取对应岗位类型与难度等级的题目
  + 根据学生用户画像（能力画像、学习行为、简历/经历）动态调整题目难度与题目类型
  + 生成5-8题结构化面试题，包含行为面试题、情境模拟题、专业技能题
- 评分逻辑：
  + AI智能评估引擎分析学生回答内容，从表达逻辑、应变能力、岗位匹配度等维度实时评分
  + 评分标准基于秒哒数据库能力评估维度表配置的维度权重
  + 生成逐题点评与整体改进建议
- 实训结束后，生成实训报告，实训结果同步更新用户画像表ability_portrait字段，自动推送对应提升课程

- 题目生成逻辑：
  + 从秒哒数据库行业标准题库表读取对应讨论主题的题目
  + 生成讨论题目与背景材料，包含讨论规则、角色设定、讨论时长
- 评分逻辑：
  + AI智能评估引擎分析学生发言内容，从团队协作、沟通说服、总结汇报能力等维度实时评分
  + 评分标准基于秒哒数据库能力评估维度表配置的维度权重
  + 生成逐题点评与整体改进建议
- 实训结束后，生成实训报告，实训结果同步更新用户画像表ability_portrait字段，自动推送对应提升课程

#### 4.7.3 竞赛答辩模拟规则
- 学生选择赛事类型、项目类型后，系统调用conducting-interviews-cn技能生成评委提问库
- 题目生成逻辑：
  + 从秒哒数据库行业标准题库表读取对应赛事类型与项目类型的题目
  + 生成5-8题评委提问，包含项目创新性、商业可行性、团队能力、答辩表现等维度
- 评分逻辑：
  + AI智能评估引擎分析学生回答内容，从项目创新性、商业可行性、团队能力、答辩表现等维度实时评分
  + 评分标准基于秒哒数据库能力评估维度表配置的维度权重
  + 生成逐题点评与整体改进建议
- 实训结束后，生成实训报告，实训结果同步更新用户画像表ability_portrait字段，自动推送对应提升课程

#### 4.7.4 JD靶向压力面试规则
- 学生从JD拆解与差距分析子页跳转时，系统自动进入JD靶向模式
- AI面试官生成逻辑：
  + 读取JD拆解结果：从秒哒数据库JD拆解记录表读取核心技能项、软素质要求、隐性门槛
  + 读取学生画像差距：从秒哒数据库用户画像表读取学生短板项
  + 生成第一题：AI面试官基于JD要求与学生短板，采用LLM生成第一题面试题，明确告知「该学生想去XX企业面试XX岗位，这份JD要求XX能力，而学生画像显示他XX短板，请在面试中死死咬住XX进行对抗性施压追问」
  + 生成追问题：AI面试官基于上一题回答内容，采用LLM生成对抗性追问题，重点针对JD要求与学生短板进行施压追问
- 追问轮次默认3-5轮，根据学生回答质量动态调整
- 面试结束后，生成深度面试报告，AI点评特别针对JD要求与学生短板进行点评
- 实训结果同步更新用户画像表ability_portrait字段，自动推送对应提升课程

### 4.8 用户画像更新规则
- 学生完成AI沉浸式实训后，实训结果回流至用户画像表，更新能力画像
- 更新权重：实训结果权重40%，能力测评结果权重60%
- 更新公式：新能力画像得分 = 实训结果得分 × 40% + 能力测评结果得分 × 60%
- 基于更新后的能力画像，生成后续学习推荐

### 4.9 简历诊断与优化规则
- 学生上传简历PDF或粘贴个人经历文本后，系统调用tailored-resume-generator-cn插件解析简历内容
- 学生输入目标岗位JD或一键拉取系统内的靶向JD记录后，系统调用AI智能评估引擎解析JD
- 系统将简历内容与JD要求进行匹配度分析：
  + 核心技能匹配度：对比简历中的技能标签与JD核心技能项
  + 项目经验匹配度：对比简历中的项目经历与JD项目经验要求
  + 软素质匹配度：对比简历中的软素质描述与JD软素质要求
  + 学历背景匹配度：对比简历中的学历信息与JD学历要求
  + 工作经验匹配度：对比简历中的工作经验与JD经验要求
- 系统生成匹配度总分（0-100分），逐条标注「符合项」（绿色标记）与「待优化项」（红色标记）
- 系统诊断简历短板项（如「缺项目经验描述」「缺团队协作经历」「缺关键词匹配」），生成改进建议
- 系统分析JD中的高频关键词，标注简历中已包含的关键词与缺失的关键词，生成关键词优化建议
- 系统联动用户画像，分析画像中的优势项与短板项，生成画像与简历的一致性分析
- 系统基于简历短板项，自动关联推荐站内实训课程或虚拟练兵场任务
- 系统调用tailored-resume-generator-cn插件，运用STAR法则和关键词匹配重写经历，生成优化简历、求职信、自我介绍
- 优化简历生成规则：
  + 基本信息：保持原简历基本信息不变
  + 教育背景：保持原简历教育背景不变
  + 项目经历：运用STAR法则重写项目经历，补充关键词，突出项目背景、任务、行动、结果
  + 工作经历：运用STAR法则重写工作经历，补充关键词，突出工作职责、成果、贡献
  + 技能标签：补充JD中要求的关键技能标签
  + 自我评价：基于JD要求与学生优势项生成自我评价
- 求职信生成规则：
  + 开头：简要介绍自己，说明求职意向
  + 正文：突出学生优势项与匹配度，结合项目经历与工作经历说明能力
  + 结尾：表达求职意愿，期待面试机会
- 自我介绍生成规则：
  + 基本信息：简要介绍姓名、学历、专业
  + 核心优势：突出学生优势项与匹配度
  + 项目经历：简要介绍代表性项目经历
  + 求职意向：说明求职意向与期待

### 4.10 批量简历诊断规则

### 4.11 班级面试考核规则

### 4.12 技能质量评估规则

#### 4.12.1 质检维度说明
- 结构完整性：检查内容结构是否完整，是否缺失必要字段或章节
- 表述清晰度：检查内容表述是否清晰，是否存在歧义或模糊表达
- 触发合理性：检查技能触发条件是否合理，是否存在逻辑冲突
- 合规风险：检查内容是否存在敏感词、违规内容、侵权风险
- 可维护性：检查内容是否易于维护，是否存在冗余或重复

#### 4.12.2 质检流程
- 用户上传待评估内容（技能包、课程内容、测评题库）
- 系统调用skill-eval-cn原理，通过Edge Function调用大模型进行质量评估
- 系统从5个维度自动检查，生成各维度得分（0-100分）
- 系统计算质量总分（各维度得分加权平均）
- 系统根据质量总分判定风险等级：
  + 低风险：质量总分≥80分
  + 中风险：60分≤质量总分<80分
  + 高风险：质量总分<60分
- 系统生成优先修复排序列表，按风险等级从高到低排序
- 系统生成质检报告，包含质量总分、各维度得分、风险等级、优先修复排序列表

#### 4.12.3 质检结果存储
- 质检结果存储于秒哒数据库技能质量评估记录表
- 质检结果包含：质检时间、内容名称、内容类型、质量总分、各维度得分、风险等级、优先修复排序列表

- 使用CDN加速静态资源加载
- 启用HTTP/2或HTTP/3协议，提升资源并行加载能力

#### 4.21.2 路由懒加载优化
- 对所有页面组件实施路由懒加载，按需加载页面代码
- 使用动态import语法实现路由懒加载
- 对大型页面组件进行代码分割，拆分为多个小模块

#### 4.21.3 资源体积优化
- 压缩HTML、CSS、JS文件，减少文件体积
- 使用Tree Shaking技术移除未使用的代码
- 优化图片资源，使用WebP格式或压缩图片质量
- 移除冗余依赖包，减少打包体积

#### 4.21.4 运行时性能优化
- 优化组件渲染性能，避免不必要的重渲染
- 使用虚拟滚动技术优化长列表渲染
- 优化数据请求，减少不必要的API调用
- 使用缓存策略，减少重复数据请求

### 4.22 用户体验深度优化规则（新增）

#### 4.22.1 加载状态优化
- 所有数据加载场景增加加载状态提示（骨架屏或加载动画）
- 加载状态提示应清晰明确，避免用户等待焦虑
- 长时间加载场景增加进度条或预计剩余时间提示

#### 4.22.2 空状态优化
- 所有列表为空场景增加空状态提示与引导操作
- 空状态提示应友好明确，引导用户进行下一步操作
- 空状态提示可包含插图或图标，提升视觉体验

#### 4.22.3 错误提示优化
- 所有错误场景增加友好错误提示，避免技术性错误信息直接展示给用户
- 错误提示应明确说明错误原因与解决方案
- 错误提示可包含重试按钮或联系客服入口

#### 4.22.4 交互反馈优化
- 所有按钮点击、表单提交、数据保存等交互场景增加视觉反馈
- 交互反馈应及时明确，避免用户重复操作
- 交互反馈可包含按钮状态变化、Toast提示、弹窗确认等

#### 4.22.5 信息层级优化
- 优化页面信息层级，突出核心信息，弱化次要信息
- 使用视觉层级（字体大小、颜色、间距）区分信息重要性
- 避免信息过载，合理使用折叠、分页、筛选等方式组织信息

#### 4.22.6 移动端适配优化
- 所有页面增加移动端适配，确保在移动设备上正常显示与交互
- 使用响应式布局或独立移动端页面实现移动端适配
- 优化移动端交互体验，如增大点击区域、优化表单输入、优化滚动体验等
